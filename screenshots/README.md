## Cara Mengambil Screenshot

1. Jalankan aplikasi dengan `npm run dev`
2. Buka browser dan akses `http://localhost:3000`
3. Ambil screenshot sesuai daftar di atas menggunakan:
   - Windows: `Win + Shift + S` (Snipping Tool)
   - Chrome: `Ctrl + Shift + I` → Device toolbar → Screenshot
4. Simpan file dengan nama sesuai daftar di folder ini
5. Ukuran yang direkomendasikan: 1280×720 pixels

## Format File

- Format: PNG (direkomendasikan) atau JPG
- Resolusi: Minimal 1280×720 pixels
- Nama file: Gunakan format `XX_nama_deskriptif.png`
